Quicknine / MEO採点シート・モードA

API自動採点ツール

P1・P5・P6・R1・R2 の5項目を、Google Places のデータから毎月ワンクリックで取得・採点します。

1APIキー

このツールが正しく動くには、Google Cloud Console で Places API・Places API (New)・Maps JavaScript API の3つが有効になっている必要があります。まだの場合は先にライブラリから有効化してください。

2データ取得

登録済み11店舗を対象に、Google Places から最新データを取得して自動採点します。

3採点結果

店舗名 P1
カテゴリ		 P5
営業時間		 P6
リンク		 R1
口コミ件数		 R2
平均星		 確認事項

4採点入力シートへ貼り付け

「採点入力」シートの8〜18行目、各列の先頭セルをクリックしてから対応する列をコピー＆ペーストしてください（列ごとに1回ずつ）。

まだデータを取得していません。APIキーを保存してから「データ取得」を押してください。
